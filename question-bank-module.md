## 1. Architecture & Design

The Question Bank module manages reusable assessment questions that can be referenced by homework and exams. Questions are versioned — each revision creates a new version, allowing historical tracking and rollback. Questions are organized by subject and can be tagged with grade level and topic.

### Core Concepts

| Concept | Description |
|---------|-------------|
| **QuestionBankItem** | A reusable assessment question with a specific type and options. |
| **QuestionType** | The format of the question (MultipleChoice, TrueFalse, ShortAnswer, Essay). |
| **Revision** | Each edit creates a new revision. Revisions are immutable once created. |
| **CreationSource** | Whether the question was created manually or generated by AI. |
| **Subject/Topic** | Taxonomic categorization for organizing questions. |
| **Question Status** | Active questions are available for use; Archived questions are hidden. |

### Revision System

```
CreateQuestion → Revision #1 (Active)
       |
       v
ReviseQuestion → Revision #2 (Active), Revision #1 (archived)
       |
       v
ReviseQuestion → Revision #3 (Active), Revisions #1-2 (archived)
```

Each revision stores the complete question state. The active revision is used for display and grading.

### Question Type Details

| Type | Options | Auto-Graded |
|------|---------|-------------|
| `MultipleChoice` | 2-6 options, one correct | Yes |
| `TrueFalse` | Fixed true/false | Yes |
| `ShortAnswer` | Expected answer text | Partial |
| `Essay` | Open-ended | No (manual review) |

### Important Frontend Implications

- **Immutable Revisions**: Once created, a revision cannot be modified. Use `ReviseQuestion` to create a new revision.
- **AI Generation**: Questions can be created via the AI module. AI-generated questions are marked with `CreationSource = AI`.
- **Homework/Exam References**: Questions are referenced by homework and exams. Archiving a question does not remove it from existing assignments.
- **Bulk Question Selection**: Use the list endpoint with subject/topic filters to build a question picker.

## 2. API Endpoints Reference

### 2.1 List Questions

#### `GET /api/tenants/{tenantId}/learning/questions`

Retrieves a paginated list of questions with optional filters.

**Authentication:** Required (Cookie-based)

**Authorization:** Permission `questions.view`

**Query Parameters:**
- `subjectId` (Guid, optional): Filter by subject.
- `topic` (string, optional): Filter by topic name (case-insensitive match).
- `type` (QuestionType, optional): Filter by question type.
- `status` (QuestionBankItemStatus, optional): Filter by status. Defaults to `Active`.
- `search` (string, optional): Search in question text.
- `page` (int, optional, default `1`): Page number.
- `pageSize` (int, optional, default `20`): Items per page (max 100).

**Response:** `200 OK`

```json
{
  "items": [
    {
      "id": "q1a2b3c4-d5e6-7890-a1b2-c3d4e5f60789",
      "questionText": "What is the result of 2 + 2?",

      "subjectId": "s1a2b3c4-d5e6-7890-a1b2-c3d4e5f60789",
      "topic": "Basic Arithmetic",
      "gradeLevel": "Grade 4",
      "status": "Active",
      "creationSource": "Manual",
      "activeRevisionNumber": 3,
      "totalRevisions": 3,
      "createdAtUtc": "2026-08-01T10:00:00Z",
      "updatedAtUtc": "2026-09-02T14:30:00Z"
    },
    {
      "id": "q2b3c4d5-e6f7-8901-b2c3-d4e5f6078901",
      "questionText": "Explain the concept of photosynthesis.",
      "type": "Essay",

```

### 2.2 Create Question

#### `POST /api/tenants/{tenantId}/learning/questions`

Creates a new question with its first revision.

**Authentication:** Required (Cookie-based)

**Authorization:** Permission `questions.manage`

**Request Headers:**
- `X-CSRF-TOKEN` (required)

**Request Body:**

```json
{
  "questionText": "What is the result of 2 + 2?",
  "type": 1,
  "subjectId": "s1a2b3c4-d5e6-7890-a1b2-c3d4e5f60789",
  "topic": "Basic Arithmetic",
  "gradeLevel": "Grade 4",
  "options": [
    { "text": "3", "isCorrect": false },
    { "text": "4", "isCorrect": true },
    { "text": "5", "isCorrect": false },
    { "text": "6", "isCorrect": false }
  ],
  "explanation": "2 + 2 equals 4 by basic addition rules.",
  "points": 5
}
```

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `questionText` | `string` | Yes | The question text. Max 5000 characters. |
| `type` | `QuestionType` | Yes | `1`=MultipleChoice, `2`=TrueFalse, `3`=ShortAnswer, `4`=Essay. |
| `subjectId` | `Guid` | Yes | Reference to a subject. |
| `topic` | `string?` | No | Topic name. Max 100 characters. |
| `gradeLevel` | `string?` | No | Grade level label. Max 50 characters. |
| `options` | `Array<QuestionOptionInput>` | Conditional | Required for MultipleChoice. 2-6 options. |
| `expectedAnswer` | `string?` | Conditional | Required for ShortAnswer. Max 500 characters. |
| `explanation` | `string?` | No | Correct answer explanation. Max 1000 characters. |
| `points` | `int` | No | Default points value. Defaults to 1. |

#### `QuestionOptionInput`

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `text` | `string` | Yes | Option text. Max 500 characters. |
| `isCorrect` | `bool` | Yes | Whether this is the correct answer. |

**Response:** `201 Created`

```json
{
  "id": "q1a2b3c4-d5e6-7890-a1b2-c3d4e5f60789",
  "questionText": "What is the result of 2 + 2?",
  "type": "MultipleChoice",
  "subjectId": "s1a2b3c4-d5e6-7890-a1b2-c3d4e5f60789",
  "topic": "Basic Arithmetic",
  "gradeLevel": "Grade 4",
  "status": "Active",
  "creationSource": "Manual",
  "activeRevisionNumber": 1,
  "totalRevisions": 1,
  "createdAtUtc": "2026-09-04T10:00:00Z",
  "updatedAtUtc": "2026-09-04T10:00:00Z"
}
```

**Possible Errors:**
- `400 Bad Request` — Validation error (`QuestionBank.InvalidOptions`).
- `401 Unauthorized` — Not authenticated.
- `403 Forbidden` — Missing `questions.manage` permission or tenant access denied.
- `404 Not Found` — Subject not found (`QuestionBank.SubjectNotFound`).

### 2.5 Revise Question

#### `POST /api/tenants/{tenantId}/learning/questions/{questionId}/revisions`

Creates a new revision with updated content. The previous revision becomes inactive.

**Authentication:** Required (Cookie-based)

**Authorization:** Permission `questions.manage`

**Request Headers:**
- `X-CSRF-TOKEN` (required)

**Request Body:**

```json
{
  "questionText": "What is the result of 2 + 2?",
  "type": 1,
  "options": [
    { "text": "3", "isCorrect": false },
    { "text": "4", "isCorrect": true },
    { "text": "5", "isCorrect": false },
    { "text": "6", "isCorrect": false }
  ],
  "explanation": "2 + 2 equals 4 by basic addition rules.",
  "points": 5
}
```

All fields are required.

**Response:** `201 Created`

```json
{
  "id": "q1a2b3c4-d5e6-7890-a1b2-c3d4e5f60789",
  "activeRevisionNumber": 4,
  "totalRevisions": 4,
  "revision": {
    "revisionNumber": 4,
    "questionText": "What is the result of 2 + 2?",
    "type": "MultipleChoice",
    "options": [
      { "id": "n1", "text": "3", "isCorrect": false },
      { "id": "n2", "text": "4", "isCorrect": true },
      { "id": "n3", "text": "5", "isCorrect": false },
      { "id": "n4", "text": "6", "isCorrect": false }
    ],
    "expectedAnswer": null,
    "explanation": "2 + 2 equals 4 by basic addition rules.",
    "points": 5,
    "isActive": true,
    "createdAtUtc": "2026-09-04T11:00:00Z"
  },
  "updatedAtUtc": "2026-09-04T11:00:00Z"
}
```

**Possible Errors:**
- `400 Bad Request` — Validation error (`QuestionBank.InvalidOptions`).
- `401 Unauthorized` — Not authenticated.
- `403 Forbidden` — Missing `questions.manage` permission or tenant access denied.
- `404 Not Found` — Question not found (`QuestionBank.ItemNotFound`).
- `409 Conflict` — Question is archived (`QuestionBank.QuestionArchived`).

## 5. Validation & Business Rules

### Backend-Enforced Rules

1. **MultipleChoice Options**: Must have 2-6 options. Exactly one option must have `isCorrect = true`.
2. **Subject Required**: Every question must reference a valid subject.
3. **Question Text Length**: Max 5,000 characters.
4. **Points Positive**: Points must be a positive integer (default: 1).
5. **Type Immutability**: Once created, the question type cannot be changed via revision. Create a new question instead.
6. **Archived Questions**: Archived questions cannot be revised. Unarchive first.
7. **ShortAnswer Expected Answer**: Required for ShortAnswer type.
8. **Points Consistency**: Points in revisions are independent — each revision can have different point values.

### Frontend Validation Recommendations

- Validate that exactly one option is marked correct for MultipleChoice.
- Show character count for question text (max 5000).
- For TrueFalse, auto-generate the two fixed options.
- Require subject selection before saving.
- Show validation errors inline for each field.

## 6. Error Handling Patterns

### Module Error Codes

| Code | HTTP Status | Description | User Action |
|------|-------------|-------------|-------------|
| `QuestionBank.ItemNotFound` | 404 | Question does not exist or belongs to another tenant. | Refresh question list. |
| `QuestionBank.RevisionNotFound` | 404 | Revision does not exist. | Refresh revisions list. |
| `QuestionBank.SubjectNotFound` | 404 | Referenced subject does not exist. | Select a valid subject. |
| `QuestionBank.InvalidOptions` | 400 | Invalid options for question type (wrong count, no correct answer). | Fix options before submitting. |
| `QuestionBank.QuestionArchived` | 409 | Cannot revise an archived question. | Unarchive first. |
| `Tenancy.AccessDenied` | 403 | Tenant context mismatch. | Verify tenant selection. |

## 7. Frontend Integration Best Practices

1. **Question Builder UI**: Create a form-based question editor with dynamic option fields for MultipleChoice.
2. **Preview Mode**: Show a live preview of how the question will appear to students.
3. **Question Type Selector**: Use a segmented control or dropdown to switch between question types.
4. **Subject Picker**: Show searchable dropdown for subject selection.
5. **AI Generation Button**: Add an "Generate with AI" button that creates a draft question via the AI module.
6. **Revision History**: Show revision timeline with diff view when comparing revisions.
7. **Archive/Restore**: Provide archive/restore toggle in the question detail view.
8. **Bulk Selection**: Build a checkbox-based question picker for homework/exam creation.
9. **Points Editor**: Allow per-question point adjustment in the homework/exam builder.
10. **Search and Filter**: Implement faceted search with subject, topic, type, and grade level filters.
